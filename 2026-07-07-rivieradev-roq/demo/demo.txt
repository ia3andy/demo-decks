======= Content post: 
Hello, I am Dr. Sigmund, and welcome to the Clinic.

For too long, codebases have suffered in silence. Spaghetti architecture. Abandonment issues after a rewrite. The deep, unspoken trauma of a `// TODO: fix later` written in 2019.

I am here to help.

## What We Treat

At the Sigmund Clinic, we specialize in the full spectrum of codebase psychological disorders:

- **Dependency Anxiety** — your `package.json` has 847 dependencies and you are afraid to update any of them.
- **Imposter Module Syndrome** — a class that pretends to follow SOLID principles but secretly does everything in one method.
- **Attachment Disorder** — developers who refuse to delete dead code because "we might need it someday."
- **Refactor Phobia** — the paralyzing fear that touching anything will break everything.
- **Commit Message Dissociation** — a condition where `git log` reads "fix", "fix again", "please work", "final fix v3".

## My Approach

I believe every codebase deserves to be heard. During our sessions, I will listen to your stack traces, examine your architectural choices without judgment, and gently guide you toward healthier patterns.

Sometimes the bravest thing a developer can do is admit: "This code needs help."

## Book a Session

If your codebase wakes you up at 3am with a production alert, if your test suite takes longer than your lunch break, or if you have ever whispered "it works on my machine" as a coping mechanism, the Clinic is open.

Let the healing begin.

===============Prompt style:



Style the post layout in `templates/layouts/post.html` and `web/app.css`. This is a Quarkus Roq site. Switch to `theme-layout: default` for full control. Page type is `DocumentPage`. Structure the template as: back link (href="/"), hero image (wrapped in `{#if page.image}`), title (`{page.title}`), date (`{page.date.longDate}`, also in `{#if}`), body (`{#insert /}`). In CSS, append: `.post` (max-width 48rem, centered, padded), `.post-back` (small, muted, inline-block), `.post-hero` (full-width, rounded, subtle shadow), `.post-title` (2rem bold, tight tracking), `.post-date` (small muted, block), `.post-body` (1.75 line-height, paragraph spacing). Match existing CSS variables from `:root`.

=== 1. Quarkus REST ===

@Path("/api/greetings")
@ApplicationScoped
public class GreetingResource {
    @Inject GreetingService service;

    @GET
    @Produces(MediaType.APPLICATION_JSON)
    public List<Greeting> list() {
        return service.findAll();
    }
}

=== 2. Spring Boot ===

@RestController
@RequestMapping("/api/greetings")
public class GreetingController {
    @Autowired
    private GreetingRepository repo;

    @GetMapping
    public List<Greeting> list() {
        return repo.findAll();
    }
}
